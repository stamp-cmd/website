```js
// findschool.js
HomePage.prototype.findsc = function() {
    // ...
    let schx = page.getViewById("sch"); // School's name TextField
    let mytext = encodeURIComponent(schx.text); // encode TextField's text
    let url = "http://www.thaidigitalschool.com/ios/findSchoolData2.php?school_name=" + mytext;

    fetchModule.fetch(url, {
        // method: "GET"
        // ...
    }).then(r => r.json())
    .then(jsonData => {
        // ...
        var navigationEntry1 = {
            moduleName: 'pages/school/school'
            context: {
                // ...
                param3: jsonData
            }
        }
    });
}
```

*[ASCII]: American Standard Code for Information Interchange
In `findschool.js`. User enter their school's name via input box with id "`sch`".

Then input is [encoded](https://en.wikipedia.org/wiki/Percent-encoding) to be valid, since input is usually non ASCII characters. And then the app makes an API request with method GET (if no method is specified, GET is implied).

`navigationEntry1` tells the program to switch to next page, and pass data inside `context`.

This is a searchbox, that will lists of all possible schools with input as substring. Let's try something generic, type in URLencoded string "โรงเรียน" ("school" in Thai).

```sh
curl "http://www.thaidigitalschool.com/ios/findSchoolData2.php?school_name=%E0%B9%82%E0%B8%A3%E0%B8%87%E0%B9%80%E0%B8%A3%E0%B8%B5%E0%B8%A2%E0%B8%99"
```

*[JSON]: JavaScript Object Notation
This return JSON file. With lists of school's name and id. (But like **lots more entries**)

```json
{
    "ok": true,
    "school": [
        { "schoolid": "xxxxxxxx", "schoolname": "xxxxxxxxx" }
    ]
}
```
(`schoolid` could be null)



`school.js` is not anything noteworthy, It just show list of school and let user select which one.
